## Adaptive archetypes

| Archetype | Compact | Medium | Expanded |
|---|---|---|---|
| Feed | App bar, feed stream, bottom navigation | Centered stream with app navigation rail | Compact nav, capped feed, permissioned university/academic shortcuts |
| List / detail | Push detail route | Two-pane when selection state is preserved | Master/detail workspace |
| Chat | Conversation list → thread | Conversation list + thread | Three-area app workspace with compact global navigation |
| Course workspace | Course list → course sections | Course list + selected course | Course navigation + posts/files/tasks in one workspace |
| Form | Keyboard-safe contained form | Centered bounded form | Centered bounded form in app shell |
| Academic records | Readable cards and filters | Two-pane term/course selection when useful | Bounded records; wide tables only for genuinely tabular workflows |
| Portal/service | Service categories and cards | Category rail + detail | Contained university portal + service detail |
| Management/table | Task-first cards | Responsive table/list | Wide app workspace with filters and scoped actions |
| Profile / ID | Identity-first, stacked sections | Profile beside account sections | Bounded identity surface; preserve Digital ID hierarchy |
| Settings | Grouped app sections | Two-column grouped settings | Contained groups, not full-width settings rows |

## Review notes

- No route, role, permission, or database policy was broadened for this visual correction.
- The conversation routes currently reuse `forums.access` because the schema has no dedicated messaging permission code. Member-scoped messaging RLS remains the data authorization boundary; a dedicated RBAC capability requires an independently justified backend change.
- Official status of a post must come from an existing trusted data/permission contract. The current `posts` model has post type and scope but no explicit `verified` flag; the UI must not invent a verification claim.
- Responsive status is recorded per screen above. Completed visual review at 390, 768, and 1440 pixels is still pending until screenshots are captured and inspected.
